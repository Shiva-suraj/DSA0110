# Assignment 5

This folder contains the Assignment 5 C++ source files copied from the source repository at the specified commit.

## Tasks
- Task01: Hospital billing with bill types and payer policies using inheritance and polymorphism.
- Task02: Exception handling for claim approval, audit logging, RAII cleanup, and allocation failure.
- Task03: Performance comparison of virtual dispatch, switch-based dispatch, std::variant, and exception handling.
- Task04: Extended hospital billing model with maternity bills and corporate payer coverage.

## Compile and run
Use a C++17 compiler:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic Task01/main.cpp -o task01
./task01
```

Repeat with the corresponding source file for Task02 through Task04.
